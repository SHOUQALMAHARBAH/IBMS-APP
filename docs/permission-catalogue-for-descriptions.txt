PERMISSION CATALOGUE — input for the Arabic one-line descriptions

186 permission codes, 12 modules. Generated from the seeded database, so this IS what the
Role screen renders — not a separate list that can drift from it.

HOW TO READ THIS
  [5-STATE]  A CRUD-shaped family. The screen shows it as ONE row with Full / View / Create /
             Edit / Delete, and its member codes are indented beneath it here. A description is
             still wanted per CODE, because each state means something different to a person.
  [toggle]   A single on/off permission. One description.

WHAT IS WANTED: one short line per code, in Arabic, saying what holding it ALLOWS — what the
person can then do on screen. Not the code restated.

The "en:" line is the description already stored in the database. It is developer-facing and
often terse: a hint, not something to translate.
