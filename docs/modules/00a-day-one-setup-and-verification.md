# ١ — **ثبّت النظام على جهازك**

**تحتاج:** **Node `20.19.0`** (`nvm use`) · **Docker**.

```bash
# ١ — انسخ المستودع ومعه الدماغ (ibms-brain) بنفس الأمر:
git clone --recurse-submodules https://github.com/SHOUQALMAHARBAH/IBMS-APP.git
cd IBMS-APP

# نسختَه من قبلٍ بلا الدماغ؟
git submodule update --init --recursive

# ٢ — مفاتيحك إنت (الملفُّ مش بالمستودع لأنّ فيه أسراراً):
cp .env.example .env

npm install

# ٣ — قاعدةُ البياناتِ المحليةُ على Docker:
docker compose up -d db

# ٤ — 🔴 هذا السطرُ أوّلاً وإلّا فشلَت الترحيلات (اقرأ التحذيرَ الأوّلَ تحت):
npm run db:provision-app-role

# ٥ — 🔴 `deploy` لا `dev` (اقرأ التحذيرَ الثانيَ تحت — وهذا أخطرُهما):
npm run db:migrate:deploy

# ٦ — ابذر البيانات: أدوارُ كلِّ مكتبٍ وكتالوجُ الصلاحيات. بلاها ما في صلاحياتٌ إطلاقاً:
npm run db:seed

# ٧ — شغّل:
npm run dev
```

**وللاختباراتِ قاعدةٌ ثانيةٌ منفصلةٌ تماماً:**

```bash
docker compose up -d db-test
npm run db:test:migrate:deploy
npm run db:test:seed
npm run test
```

## 🔴 التحذيرُ الأوّل — **`db:provision-app-role` ما تتخطّاه**

النظامُ يتّصل بقاعدةِ البياناتِ **بدورٍ محدودِ الصلاحياتِ** اسمُه `ibms_app`. **والترحيلاتُ تعطيه صلاحياتٍ باسمِه ولا تنشئه.** ودورُ Postgres **شيءٌ على مستوى العنقودِ كلِّه**، فيبقى حتى لو حُذِفَت قاعدةُ البياناتِ وأُعيد إنشاؤها.

⟶ **وكلُّ جهازٍ شغّل هذا المنتجَ كان الدورُ عنده أصلاً، وهذا بالزبط سببُ أنّ الثقبَ بقي غيرَ مرئيّ.** **وعلى جهازٍ جديدٍ فعلاً، أوّلُ ترحيلةٍ تمنح صلاحيةً توقف `migrate deploy` ميتاً.** *(يحتاج `APP_DB_PASSWORD` في بيئتك.)*

## 🔴 التحذيرُ الثاني — **`migrate deploy` لا `migrate dev` · وهذا أخطرُ سطرٍ في الورقة**

**كان مكتوباً `npm run db:migrate:dev`، وانصحّح في ٤ تشرين الثاني بعد مشيةٍ على عنقودٍ جديدٍ فعلاً.**

`migrate dev` **ينزّل الـ١٦٤ ترحيلةً كلَّها صحيحةً**، ثمّ **يسألك: «اكتب اسماً للترحيلةِ الجديدة»** — لأنّ `schema.prisma` ما يقدر يعبّر عن أشياءَ تنشئها الترحيلاتُ، فيقرأُها على أنّها انحرافٌ يلزم إلغاؤه.

**والترحيلةُ اللي يعرض يكتبَها تحذف:**
**١٦ مفتاحاً أجنبياً** — **خمسةَ عشرَ منها قيودُ `*_same_org_fkey` اللي تمنع تسرُّبَ بياناتِ مكتبٍ لمكتبٍ آخر** · **و٣ فهارسِ بحثٍ نصّيّ** · **و٦ أعمدةٍ محسوبة**.

⟶ **تكتب اسماً وتضغط Enter، فيصير عزلُ المكاتبِ أضعفَ على جهازِك بالسكوت — ولا رسالةَ خطأٍ ولا شي.**

**و`migrate deploy` ينزّل المعلَّقَ وبس:** لا يسأل، ولا يقارن بـ`schema.prisma` أبداً. **ومُتحقَّقٌ منه على عنقودٍ جديد: ١٦٤ ترحيلةً نزلَت · ١٣٨ جدولاً عليها حمايةُ الصفوف (١٢ منها مُجبَرة) · والـ١٥ مفتاحَ `same_org` كلُّها موجودة.**

## وقاعدتان على البياناتِ والأسرار

**⛔ ما حدٌ يجرّب تغييرَ مخطَّطٍ على `db`.** **كلُّ تجربةٍ تصير على `db-test` أوّلاً.** *(ولهذا `db:test:migrate:dev` موجودٌ — للتجربةِ وحدَها.)*

**⛔ ولا حدٌ يلمس `.env` ولا يطلب مفاتيحَ حدٍّ ثاني.** الخاناتُ اللي فيها تشفير: **ولّد مفاتيحَك المحليةَ إنت.** **وإنت تشتغل على بياناتٍ مزروعةٍ تجريبية، لا على بياناتِ عميلٍ حقيقيٍّ أبداً.** ⟶ **ولا قيمةَ سرٍّ تُطبَع ولا تُنسَخ في أيِّ تقريرٍ أو رسالة — يُسمّى المتغيّرُ، ولا تُذكَر قيمتُه.**

# ٣ — 🔴 **قبل أوّلِ سطرِ كود: قِس مديولَك بستّةِ أوامر**

**ما حدٌ يكتب سطراً قبل ما ينشر «شو موجودٌ وشو ناقص» مقيساً من الكود.** **والقياسُ هو تسليمُك الأوّل.**

المثالُ تحت مشغَّلٌ فعلاً على **مديولِ العملاء**. **بدّل `customer` باسمِ مديولِك.**

```bash
# ١ — كم جدولاً في النظام كلِّه
grep -c "^model " packages/db/prisma/schema.prisma                    # → ١٦١

# ٢ — كم مساراً مبنيٌّ في مديولك
grep -c "@Get(\|@Post(\|@Patch(\|@Delete(" \
  apps/api/src/modules/customer/customer.controller.ts

# ٣ — شو الشاشاتُ اللي إلها علاقة
ls "apps/web/app/(app)" | grep -i customer

# ٤ — كم صلاحيةً تحرسه
grep -c 'code: "customer' packages/db/prisma/seed-data/permissions.ts

# ٥ — شو الاختباراتُ اللي تحرسه
ls apps/api/test/ | grep -i customer

# ٦ — في مساراتٌ مبنيّةٌ وما حدٌ يناديها؟
npm run check:unreachable-routes
```

**⚠ وتحذيرٌ على الأمرِ السادس:** **هذي الأداةُ تعدُّ ذكرَ المسارِ وصولاً، لا نداءً فعلياً** — فأرقامُها **أرضيةٌ لا حقيقة**. **انكشفَت لمّا طلع إنّ المكتبَ ما يقدر يعدّل سجلَّ شركةِ تأمينٍ إطلاقاً والأداةُ تقول إنّه موصول.** ⟶ **اقرأ نتيجتَها، ولا تثق فيها.**

# ٤ — **إحدى عشرةَ قاعدةً للتحقّق — وكلُّها وُلِدَت من غلطٍ مقيسٍ لا من حرص**

**١ · ما في رقمٌ يُنقَل، كلُّ رقمٍ يُقاس.** **وإذا ما قدرتَ تعيد إنتاجَ رقمٍ كتبتَه، سمِّ الأمرَ اللي أعطاك إيّاه.**

**٢ · والرقمُ يحمل طريقةَ عدِّه.** *(نفسُ الملفِّ انعدَّ بطريقتَين فطلع ٣٦ و٦٢ — ولا وحدةٌ غلط، بس من قرأ الرقمَ بلا طريقتِه فهم غيرَ اللي صار. وملفّاتُ القراراتِ اليومَ: ٤٩ بوحدةٍ و٥٦ بوحدةٍ ثانية، والاثنانِ صح.)*

**٣ · كلُّ مديولٍ يفتح بقياس، والقياسُ أوّلُ تسليم.**

**٤ · السؤالانِ مش نفسُ السؤال:** «أيُّ اختباراتٍ تشغّل اللي لمستُه؟» **≠** **«أيُّ اختباراتٍ تحكم على اللي حرّكتُه؟»** *(صار فعلاً: واحدٌ غيّر جدولَ صلاحيات، شغّل اختباراتِ الصلاحيات، طلعوا أخضر — واللي يحكم عليه كان اختباراً باسمٍ ثانٍ تماماً. البناءُ طلع أحمر.)*

**٥ · «أكبرُ ممّا يبدو» = بلّغ وقِف.** **ممنوعٌ تكمّل لأنّك «قاربتَ تخلص». والحجمُ المقيسُ هو التسليم.**

**٦ · ازرع عطباً بكلِّ دفعة.** **خرّب اللي بنيتَه عن قصدٍ وشوف الاختبارَ يصرخ.** ⟶ **ما صرخ؟ يعني ما بنيتَ حارساً، بنيتَ ادّعاءً.** *(وحالةٌ واحدةٌ الزرعُ ما يثبت فيها شيئاً — إصلاحُ توقيت: لأنّ «ينجح محلياً» هو العطلُ نفسُه. ساعتَها اكتب إنّه ما ثبَت، لا تدّعِ.)*

**٧ · شغّل البوّاباتِ بعدَ آخرِ تعديلٍ، لا قبلَه.**

**٨ · الملفّاتُ المشتركةُ يُضاف إلها، ولا يُعدَّل فيها.** كلُّ واحدٍ يضيف سطرَه آخرَ الملف.

**٩ · 🆕 أمرٌ يُخفى فشلُه يقول إنّه نجح.** `npm run lint | tail` يرجّع نتيجةَ الأنبوبِ لا نتيجةَ الفحصِ — فقال «نجح» والفحصُ فاشل. **و`git fetch --quiet … 2>/dev/null` أخفى سطراً يقول إنّ الجلبَ فشل، فقُرِئَت حالةٌ قديمةٌ على أنّها الحاضر.** ⟶ **فلا يُخفى مسارُ فشلِ أمرٍ تُبنى على نتيجتِه قراءة. وقياسٌ يُخفى فشلُه ليس قياساً.**

**١٠ · 🆕 عدّانِ مستقلّانِ يصلانِ لنفسِ الجوابِ هو السببُ الوحيدُ للثقةِ بالجواب — بشرطِ أن يكونا مستقلَّينِ في الشيءِ اللي يمكن يكون غلطاً.** **قرارٌ مذكورٌ عشرَ مرّاتٍ بقي بلا ملفٍّ وبلا سطرٍ في أيِّ سجلٍّ طولَ عمرِ المشروع، لأنّه لم يُذكَر لحالِه ولا مرّةً بل دائماً داخلَ جملةِ «القراران ٣٢ و٣٣»** — **فعدّانِ اتّفقا على رقمٍ غلطٍ لأنّهما تشاركا نفسَ العمى.**

**١١ · 🆕 جملةٌ تقول «ما في» تُقاس من جديدٍ قبل أن تُصدَّق — ولو كانت منّا.** **والغيابُ هو الوحيدُ اللي يفسد بالسكوت**، لأنّ الكودَ يُبنى ولا أحدٌ يرجع يشيل الجملة. *(في ٨ تشرين الثاني وحدَه: خمسُ جُمَلِ غيابٍ في ورقاتِنا طلعَت غلطاً — تقويمُ العُطَلِ وطلبُ التسعيرِ والاستيرادُ والقائمةُ والمزامنة، كلُّها مبنيّةٌ وكلُّها كانت مكتوبةً «غائبة».)*

## ⛔ وثلاثُ ممنوعاتٍ ما إلها استثناء

**١ · ما حدٌ يأخذ صلاحيةً عشان شاشةٌ تشتغل.** **الشاشةُ ما اشتغلَت؟ افهم ليش ممنوع، لا تفتح البابَ.**

**٢ · ولا كلمةٌ عربيةٌ تُخترَع.** **الكلمةُ تُقَصُّ من نصٍّ شغّالٍ أو تكون من الإدارة. ثالثَ ما في.**
```bash
grep -rn "الكلمة" apps/web/lib/i18n/translations/
```
*(آخرُ مرّة: ١٠ من ١١ كلمةً كانت موجودةً أصلاً. ومرّةً ثانية: كلمةٌ كان ناقصَها تصريف — والتصريفُ نفسُه قرارُ الإدارةِ لا قرارُك.)*

**٣ · ولا حدٌ يلمس `.env`.** **ولا حدٌ.**

## الخلاصةُ بستِّ جُمَل

**١.** **`migrate deploy` لا `migrate dev`** — السطرُ الوحيدُ اللي يضعف عزلَ المكاتبِ بالسكوت.
**٢.** **شغّل البوّاباتِ قبل ما تلمس إشي**، عشان تعرف إنّ الأخضرَ أخضر.
**٣.** **قِس مديولَك بستّةِ أوامرَ وانشر النتيجةَ قبل أوّلِ سطر.**
**٤.** **قِس، لا تنقل** — والوثائقُ تفسد والكودُ لا، **والرقمُ يحمل طريقةَ عدِّه**.
**٥.** **ازرع عطباً** — اختبارٌ ما صرخ مرّةً ليس حارساً.
**٦.** **أكبرُ ممّا بان؟ بلّغ وقِف.** **مش فشلاً — هذا المطلوب.**
